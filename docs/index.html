About AMBench

AMBench is the first benchmark to provide full taxonomic coverage of the agent memory design space — 27 core cells spanning 3 functions (factual, experiential, working) × 3 forms (token-level, parametric, latent) × 3 dynamics (formation, retrieval, evolution), plus 4 extended dimensions (temporal, multimodal, security, multi-agent).

Submit your memory system via PR and appear on the leaderboard. All submissions are automatically validated and ranked.

The leaderboard uses a PR-based pipeline — add a submission JSON to leaderboard/submissions/ following template.json and open a pull request.
